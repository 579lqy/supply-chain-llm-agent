Supply-Chain · LLM Agent

LLM 版供应链 RAG Agent

把"关键词匹配原型"升级为由 LLM function calling 驱动的 Agent：用 LLM function calling 做意图路由与工具调度，用向量检索替代 TF-IDF，用LLM 生成替代模板填空。核心原则：LLM 管"脑"，确定性代码管"手"——数值计算与检索执行一律由真实工具完成，模型不碰数。

RAG + Agent Function Calling MCP 真实数据工具 离线向量检索 双后端兜底 防幻觉评测

为什么升级：关键词版 vs LLM 版

下方是每个环节的"谁来做决定"。关键词版里所有智能都在代码规则里；LLM 版把理解、调度、表达交给模型，计算与检索仍由确定性代码执行。

环节关键词版LLM 版
意图路由三张关键词表命中 → rag/tool/hybridLLM function calling 自己选工具 + 抽参数
知识检索TF-IDF 字符匹配 + 同义词补丁离线向量召回（BGE-small-zh），不可用时回退 TF-IDF
参数抽取正则 sku\d+ / 城市枚举 / 低于\d+LLM 直接从自然语言产出结构化参数
答案合成填空模板LLM 生成结构化 JSON（带约束防幻觉）
真实数据计算两版一致：安全库存 / EOQ / ABC 等一律由 mcp_tools.py 真实计算，模型不臆测

架构：LLM 管"脑"，代码管"手"

蓝色节点＝调用 LLM 的地方；绿色＝真实数据工具（绝不让模型算数）；灰色虚线＝无 API Key 时自动回退到关键词逻辑，保证 demo 永远可跑。

双后端：没 Key 也能跑，有 Key 立刻切换 LLM

RuleBasedBackend（默认）

复用关键词版链路，零外部依赖。21 条评测与冒烟测试 100% 复现，作为离线兜底与对照基线。适合快速看效果、做演示。

OpenAIBackend（LLM）

OpenAI 兼容接口：DeepSeek / 通义 / 智谱 / 本地 Ollama 都能用（只换 base_url）。任一 LLM 环节失败自动回退规则，不崩。

三分钟跑起来

# 零依赖（默认规则后端）
python src/demo.py

# 开启 LLM
pip install openai
set LLM_BACKEND=openai
set OPENAI_API_KEY=sk-xxx
set OPENAI_BASE_URL=https://api.openai.com/v1
set OPENAI_MODEL=gpt-4o-mini
python src/demo.py

# 升级向量检索（无需 key）
pip install sentence-transformers
python src/demo.py
